# FixGo

Proyecto MVP FixGo.

Estructura creada en `C:\Development`.

Pasos rápidos:

- Asegúrate de cerrar y volver a abrir la terminal para que el PATH de usuario se aplique.
- Ejecuta `flutter doctor`.
- Desde `C:\Development\projects\FixGo` crea el proyecto con `flutter create .` o `flutter create fixgo` si quieres crear carpeta nueva.
